The push model is where a client connects to the server, the server sends data to the client, and the client does not have to request anything.

>[!NOTE]
>One example of an application that uses a push model is RabbitMQ.

The client has a socket that is constantly connected to the server and simply 'waits' to receive data. Its main benefit is that the system is real-time.

Its drawbacks are that the client **must** be online and connected in order to receive data. Also, the client implementation has to be able to handle the load pushed by the server.
